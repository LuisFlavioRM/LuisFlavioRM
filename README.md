## 👨‍💻 Sobre mim | About me

Sou desenvolvedor de software brasileiro, atuando na área de tecnologia desde 2021, com foco em desenvolvimento mobile, backend Java e administração de bancos de dados.

Trabalho com desenvolvimento de aplicações, APIs REST, integração entre sistemas, automação de processos e soluções corporativas. Busco construir sistemas eficientes, seguros e de fácil manutenção, aplicando boas práticas de engenharia de software e arquitetura.

- 📱 **Mobile:** desenvolvimento multiplataforma com Flutter e Dart.
- ☕ **Backend:** desenvolvimento Java, APIs e integrações.
- 🗄️ **Database:** administração, desenvolvimento e otimização de SQL Server e T-SQL.
- 🔗 **Integrações:** sistemas corporativos, ERP, APIs REST, JSON e XML.
- 🤖 **Automação:** scripts, bots e ferramentas para produtividade.
- 🎓 **Formação:** Análise e Desenvolvimento de Sistemas.
- 🚀 **Interesses:** arquitetura de software, DevOps, inteligência artificial e novos produtos digitais.

> Building software. Solving real problems.
