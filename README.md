## Sobre mim

Sou desenvolvedor de software com experiência na área de tecnologia desde 2021. Minha atuação conecta desenvolvimento **backend em Java**, aplicações **mobile com Flutter e Dart** e **administração e desenvolvimento de bancos de dados SQL Server**.

Tenho experiência com integrações entre sistemas, APIs, soluções B2B, automação de processos e otimização de consultas SQL. Gosto de entender o problema de ponta a ponta: da regra de negócio e da modelagem dos dados até a aplicação e sua entrega ao usuário.

Atualmente, também desenvolvo projetos pessoais e estudo arquitetura de software, DevOps e integrações com inteligência artificial.

## Projetos pessoais

### DevBridge Terminal

Ambiente web para acesso remoto a terminais e gerenciamento de projetos de desenvolvimento. Explora comunicação em tempo real, sessões de terminal e organização de workspaces.

`Angular` · `NestJS` · `TypeScript` · `WebSocket` · `node-pty`

### EspetoControl

Sistema de gestão comercial para pequenos estabelecimentos, com controle de mesas, comandas, pedidos, fluxo de cozinha e pagamentos. O protótipo funcional utiliza armazenamento local.

`Flutter` · `Dart` · `SQLite` · `Drift` · `Riverpod`

### Telegram Monitor

Projeto de automação pessoal para acompanhar mensagens de grupos e canais, aplicar filtros configuráveis e enviar alertas privados de promoções. A arquitetura contempla persistência de dados e controle de acesso.

`Python` · `Telethon` · `Telegram Bot API` · `PostgreSQL`
